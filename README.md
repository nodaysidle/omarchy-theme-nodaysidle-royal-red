# Nodaysidle Royal Red

> F1 Telemetry & Scuderia Monogram — Bespoke Omarchy Theme for NODAYSIDLE

## Philosophy

Tailored for ultra-high contrast focus, zero GPU polling overhead, and relentless shipping sprints.

## Files
- `colors.toml` — Core terminal, GTK, and desktop palette
- `shell.toml` — Bespoke top bar, controls, notifications, and popups
- `hyprland.lua` — Curvature, borders, gaps, dimming, and smooth beziers
- `foot.ini` — Foot terminal ANSI color specification
- `btop.theme` — btop system telemetry skin
- `backgrounds/` — High-resolution 2560x1440 wallpapers

## Installation

```bash
./install
omarchy theme set "Nodaysidle Royal Red"
```
